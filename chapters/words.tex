国语人一般规律：
\begin{itemize}
    \item 国多中性，零冠词
    \item 语用isch全中性
    \item 男加er女加in
\end{itemize}
特殊：
\begin{itemize}
    \item 两伊苏丹是阳性，瑞蒙土乌斯阴性，美利荷兰是复数。
    \item 中性国家不加冠，其余国家要加冠。
    \item 德国人Deutsche变格同形容词 (Dekl. wie Adj.)
    \item 中英法俄不是er：Chinese, Engländer, Franzose, Russe (注意变音)
\end{itemize}
介词：
\begin{itemize}
    \item nach + 中性国 (强调去某地)
    \item in + 带冠国 (强调进入领地)
\end{itemize}
